# 일단가 v2.7 · 자유로운 루트 편집

## 적용
1. ZIP을 새 폴더에 풀고 Android Studio에서 ildanga_v2_7 폴더를 엽니다.
2. Gradle 동기화 후 실행 기기를 켜져 있는 PLEOS로 선택하고 app을 Run 합니다.
3. 기존 앱을 삭제하지 마세요. 동일한 패키지/서명으로 업데이트하면 이 기기에 저장된 코스를 유지합니다. 서명 충돌 시 먼저 기존 앱의 내 루트 → 백업으로 데이터를 보관하세요.
4. 기존 카카오 연결 서버 창이 살아 있으면 그대로 사용합니다. 꺼져 있으면 CONNECT_PLACES.cmd 실행 후 로컬 창에 키를 입력합니다.
5. 에뮬레이터를 재시작해 연결이 끊기면 CONNECT_PLACES.cmd를 다시 실행하거나 이전 안내의 adb reverse 설정을 적용합니다.

## 이용
- 대전 코스 → 성심당 → 다른 빵집 찾기: 실제 장소를 자동 검색하고 후보 한 곳을 표시합니다.
- 직선 5km 안에 검색된 성심당 대전역점/롯데백화점/DCC점이 있으면 먼저 표시합니다. 다음은 성심당 관련 매장, 그다음 주변 빵집입니다. 존재하지 않는 결과를 만들어 넣지 않습니다.
- 새로고침 · 다음 장소: 조회한 후보를 한 곳씩 순환합니다. 마지막 뒤에는 첫 후보로 돌아갑니다. 실패 시 다시 검색 버튼으로 재요청합니다.
- 장소정보 또는 이 장소로 바꾸기를 누릅니다. 선택한 방문지만 바뀝니다.
- 방문지 목록 끝 ＋ 장소 추가: 마지막 방문지 기준 5km 안에서 이름/종류를 검색해 끝에 추가합니다. 최대 12곳.
- 순서·삭제 편집: ↑ ↓로 순서를 바꾸고 삭제합니다. 최소 2곳을 유지합니다.
- 큰 내 루트 저장하고 보기: 이름을 정해 저장하면 해당 루트 지도로 이동합니다.
- 내 루트에서 다시 열고 수정 후 저장하면 같은 개인 루트를 갱신합니다. 원본 커뮤니티 코스는 수정하지 않습니다.

## 확인 범위
DOM 기반 자동 검증: 후보 한 곳 표시, 분점 우선, 다음 후보, 단일 교체, 추가, 순서 변경, 저장/덮어쓰기/재열기, 빈 결과 및 늦은 응답 무시, 기존 기능 회귀 검증 통과.
이 환경에서는 Android APK 빌드와 실제 PLEOS 화면 테스트를 수행하지 못했습니다.
영업정보/실제 후기 요약/음성 AI/PLEOS 내비 연동은 이번 변경에 포함되지 않습니다. 장소 검색은 기존 Kakao 연결 서버를 사용합니다. 내 루트는 이 기기의 로컬 저장이며 다른 컴퓨터로 자동 동기화되지 않습니다.
