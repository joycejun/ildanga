# 하트 찍고, 골목 걷고, 청주에서 쉬어가기

일단가 편집 코스 초안 · 관광공사의 공식 코스나 실제 방문 후기 아님.

청주 하트나무 가로수길 → 성안길 → 수암골

1. 하트나무 가로수길: 북문로 일원에서 사진을 찍는 출발점.
2. 성안길: 도심 골목을 둘러보고 식사 장소를 선택하는 중간 지점.
3. 수암골: 마지막 산책과 휴식 구간. 구체적인 카페는 현지 검색으로 선택.

추천 문구: 하트 모양 나무 앞에서 한 장, 성안길에서 한 끼, 수암골에서 잠깐의 여유.

체류시간을 포함한 총 소요시간, 주차, 영업 여부, 정확한 좌표와 실시간 도로 경로는 미확인. 지도에 실제 코스로 넣기 전 장소 검색으로 확정해야 함. 사진은 복제하지 않았으며 실제 후기는 별도로 수집/요약해야 함.
