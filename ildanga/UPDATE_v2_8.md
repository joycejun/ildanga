# 일단가 v2.8 · 지도와 함께 바뀌는 장소

## 실행
ZIP을 새 폴더에 풀고 ildanga_v2_8을 Android Studio에서 열어 동기화한 뒤, 켜진 PLEOS에 app을 Run합니다. 기존 앱을 삭제하지 마세요. 같은 패키지/서명으로 업데이트하면 저장된 코스를 유지합니다. 서명 충돌 시 기존 앱의 내 루트 → 백업으로 먼저 보관하세요.
카카오 연결 서버가 켜져 있으면 그대로 사용합니다. 별도 키는 필요 없습니다. 서버가 꺼졌다면 CONNECT_PLACES.cmd에 기존 키를 입력하세요. 에뮬레이터 재시작 시 adb reverse 연결을 다시 설정해야 할 수 있습니다.

## 변경
- 오른쪽 새로고침: 교체 팝업 없이 다른 실제 장소 정보로 전환하고 왼쪽 지도 경로도 다시 계산합니다.
- 이전으로: 선택한 방문지의 직전 추천으로 되돌립니다.
- 처음 장소로: 해당 코스를 열었을 때의 원래 방문지로 되돌립니다. 대전 기본 코스는 성심당 본점입니다.
- 이 되돌리기 이력은 현재 편집 세션에서 유지합니다. 저장한 코스를 새로 열면 저장된 장소가 처음 장소입니다.
- 다른 방문지는 유지합니다. 순서를 바꿔도 해당 장소의 되돌리기 이력을 따라갑니다.
- 빵집 추천은 Kakao 업종 정보로 제과·베이커리·떡·디저트 및 성심당 음식점/카페를 확인합니다. 휴대폰 매장 등 이름만 비슷한 장소는 제외합니다.
- 원래 장소 기준 직선 5km, 성심당 분점 우선. 새로고침은 조회된 후보를 순환합니다. 검색 결과가 없거나 실패하면 현재 장소를 유지합니다.
- '1번째 방문' 문구 삭제. 상단 링크는 '공식 홈페이지 이동'으로 변경. 확인된 공식 URL이 없으면 비활성화하고 미확인 표시.
- 하단 영업정보·장소정보 버튼 삭제. 후기 원문 링크는 유지합니다.
- + 장소 추가, 순서/삭제, 내 루트 저장 후 지도 이동은 유지합니다.

## 확인 범위
자동 검증 통과: 팝업 없는 직접 교체, 경로 데이터 변경, 다른 방문지 유지, 업종 필터(휴대폰 매장 제외), 이전/처음 복원, 순서 이동 후 복원, 오류/빈 결과 시 현재 루트 보존, 기존 추가/저장/재열기 흐름.
실제 APK 빌드·PLEOS 화면 검증은 이 환경에서 수행하지 못했습니다. 지도 경로는 OSRM 추정이며 실시간 교통/PLEOS 내비 연동이 아닙니다. 영업시간 실시간 확인 및 실제 후기 요약은 아직 미연동입니다.
