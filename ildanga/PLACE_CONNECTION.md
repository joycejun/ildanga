# v2.6 자동 연결 도구

PLEOS를 켜고 **CONNECT_PLACES.cmd**를 더블클릭하세요.
이 도구가 SDK/adb 탐색 → 기기 선택 → REST API 키 비공개 입력 → 실제 API 확인 → adb reverse → 로컬 서버 실행을 처리합니다.
Python 3가 필요합니다. 키가 없다면 https://developers.kakao.com 에서 앱의 REST API 키를 먼저 발급해야 합니다.
입력은 화면에 표시되지 않으며 키를 파일이나 APK에 저장하지 않습니다. 키 확인 요청은 성심당 1회 검색입니다.
설정 성공 메시지가 나온 뒤 일단가의 '다른 빵집 찾기 → 주변 검색'을 누르세요. 서버 창은 열어 둡니다.
현재 대화에서는 학교 컴퓨터에 접속하거나 키를 발급/입력한 상태가 아닙니다. 이 도구를 실행해야 연결됩니다.

# 실제 장소 검색 연결 (v2.5)

## 지금 바로 되는 것 — 키 불필요
- 성심당 본점/한밭수목원의 공식 안내를 출처·확인일과 함께 앱에서 표시.
- 영업정보 → 공식 최신 안내 페이지 열기. 임시휴무는 확인되지 않았다고 구분.
- 장소정보 → 공식 지도 링크 열기. 실제 지도 페이지의 영업시간·후기 확인.
- 다른 빵집 → 공식 분점 정보(대전역/롯데백화점) 또는 외부 카카오맵 주변 검색.
- 지도의 경로 미리보기는 기존 OpenStreetMap/OSRM. 이것이 현대차 기본 내비가 되는 것은 아닙니다.

## 앱 안에서 실제 주변 장소 목록 받아 교체하기 — 카카오 키 필요
1. https://developers.kakao.com 에서 자신의 앱을 등록하고 Kakao Map/Local API 사용 조건과 REST API 키를 확인합니다.
   공식 문서: https://developers.kakao.com/docs/ko/kakaomap/rest-api
2. 학교 컴퓨터에 Python 3를 설치합니다. 별도 pip 패키지는 필요 없습니다.
3. 프로젝트 폴더의 `start_places.cmd`를 실행하고 REST API 키를 입력합니다. 키는 표시/저장되지 않으며 실행 중인 서버 프로세스에서만 사용됩니다. 창을 열어둡니다.
4. Android Studio Terminal(PowerShell)에서 아래 명령을 실행합니다.
```powershell
$adb = Join-Path $env:LOCALAPPDATA 'Android\Sdk\platform-tools\adb.exe'
& $adb devices
& $adb reverse tcp:8765 tcp:8765
```
여러 기기가 연결되어 있으면 `& $adb -s <Pleos기기번호> reverse tcp:8765 tcp:8765`처럼 지정합니다.
5. 일단가를 Run → 대전 빵지순례 → 다른 빵집 찾기 → 주변 검색 또는 성심당 분점.
6. 실제 이름·주소·전화·거리순 결과를 확인하고 '이 장소로 바꾸기'를 누릅니다.

반경은 선택 장소 기준 직선 5km이며 현재 차량 위치 기반 검색이 아닙니다. 인기 순위/우회 운전시간은 제공하지 않습니다.
바뀐 장소는 공급자의 좌표를 사용합니다. 조회 오류/키 누락/시간 초과는 결과 화면에 표시됩니다.
API 키는 채팅으로 보내거나 APK/저장소에 넣지 마세요. 개인 개발 계정에서 직접 설정합니다.

## 영업시간과 후기의 구분
카카오 장소 검색 API 응답에는 영업시간·리뷰 본문이 없습니다. 따라서 주변 검색 결과는 '영업 확인 필요'를 유지하고 실제 장소 페이지로 연결합니다.
공식 운영시간은 2026-11-09에 확인한 저장 정보이지 실시간 휴무 API가 아닙니다.
한밭수목원은 동원/서원의 휴원일이 다르므로 전체 휴무로 표시하지 않습니다. 공휴일 예외·임시 통제 여부는 공식 공지에서 확인해야 합니다.
실제 후기 요약은 아직 미연동입니다. 허위 리뷰 예시를 실제 장소 정보와 혼합하지 않도록 v2.5에서는 제거했습니다.
추후 영업시간/리뷰 제공 계약이 있는 데이터 공급자와 연결해야 앱 내부 실시간 휴무·AI 요약을 구현할 수 있습니다.

## 배포용 서버
지금 서버는 127.0.0.1에만 바인딩하는 개발 서버입니다. 기기 재시작 시 adb reverse를 다시 실행하세요.
배포 시 HTTPS 서버·인증·요청 제한·비용 제한을 설정하고 Gradle 속성 `placesApiBase=https://내서버`를 사용합니다.
디버그 빌드만 127.0.0.1 HTTP를 허용하고 릴리즈는 HTTPS만 허용합니다.
이 프로젝트를 제공하면서 서버를 배포하거나 유료 서비스를 활성화하지 않았습니다.

## PLEOS 기본 길 안내
공식 NaviHelper SDK는 목적지/경유지 설정과 내비 화면 요청을 제공합니다.
https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/NaviHelper/intro
현재 공개 가이드는 v3.0.5 기준입니다. 사용 중인 에뮬레이터 v2.1.0의 SDK/권한 호환성 확인이 필요합니다.
현재 ZIP에는 NaviHelper가 연결되지 않았으며 외부 지도 버튼을 통해서만 길찾기 화면을 엽니다.
