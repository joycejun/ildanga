빈 후기 요약 수정

server/reviews_service.py 하나만 기존 프로젝트 같은 위치에 덮어쓰기. 서버 창 종료 후 CONNECT_REVIEWS.cmd 재실행, 앱 완전 종료 후 재실행. Android 재빌드 불필요.

기존 과반 조건을 반복 언급 기준으로 조정: 특징/팁 서로 다른 후기 2개 이상, 불만 3개 이상 및 표본 25% 이상. 1건 불만 제외. 전체 이용자의 다수/공감으로 일반화 금지. 문장 옆에 모델이 선택한 근거 후기 수/표본 수 표시. 근거 부족 문단은 생략, 모두 없으면 안내 한 줄. 최대 3문단. 표본 최대 8개. 별점/공감 미연동. 의미상 근거 판단은 AI이며 개수 검증만으로 요약 사실성이 보장되지는 않음.

모의 테스트 통과. 실제 수신 원문과 사용자 모델 응답을 확인하지 못했으므로 실제 결과 보장 불가.
