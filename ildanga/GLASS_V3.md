# 일단가 Glass v3 (시안 적용 레이어)

참고 이미지 3장(홈 / 채팅 / PLEOS 길안내)의 보라색 글래스 디자인을 기존 코드 위에 얹는 **표시 전용** 레이어입니다.
카카오·TourAPI 검색, PLEOS 내비 SDK 연결, Gleo 액션, localStorage 형식, Java 코드는 건드리지 않습니다.

## 적용
    python apply_glass_v3.py <프로젝트 루트>      # settings.gradle 이 있는 폴더
그 뒤 Android Studio에서 다시 Run. 되돌리기: `app/src/main/assets/index.html.before-glass-v3.bak` 로 복원.
(여러 번 실행해도 안전합니다. Aurora 레이어 다음에 로드되므로 aurora-app.* 가 있어야 내부 화면이 같은 톤으로 보입니다.)

## 포함 파일
- `glass-v3.css` / `glass-v3.js` — 레이어 본체
- `fonts/PretendardVariable.woff2` + `PRETENDARD-OFL.txt` — Pretendard (SIL OFL 1.1) 글꼴, 오프라인 번들

## 바뀌는 것
- 글꼴: Pretendard / 배경: 한강 노을 사진을 흐리게 + 보라색 막
- 상단: 로고(자동차 곡선) + 프로필 원형 버튼, 기존 상단 탭·시계 숨김
- 하단 플로팅 탭바 홈/코스/저장/마이 (`glass-v3.js` 의 `TABS` 배열에서 이름·연결 페이지 변경)
- 홈: "오늘은 어디로 갈까?" 카드, 검색창, 코스 찾기, 추천 칩, 인기 코스 카드(세로형 / 가로 화면에서는 2열)
- 채팅창(Gleo): 로봇/사용자 아바타 말풍선, 테마 칩, 전송 버튼
- PLEOS 길안내 창: 구간 행(1구간·2구간), "N구간 길안내 시작", "N구간 보기"

## 탭 연결 (바꾸고 싶으면 TABS 수정)
홈→home / 코스→community(+route 화면에서도 켜짐) / 저장→saved / 마이→요약 창(저장·내 루트·공유 개수, 로그인 없음)

## 확인한 것 / 못 한 것
- Chromium으로 700×470, 1920×720, 390×844 화면 렌더링 확인, 페이지 오류 없음.
- 기존 `tests/flows.cjs` 통과 여부는 별도 기재. APK 빌드·실제 PLEOS 기기 확인은 하지 못했습니다.
- 시안의 "PLEOS와 연동해 수정" 문구는 연동 미확인이라 기존의 "앱 내부 명령 테스트" 안내를 유지했습니다.

## v3.1 추가
- 마이 탭: 내 코스 목록 + "새 코스 만들기" / 수정 / 삭제(2번 눌러 확인)
- 코스 공유 버튼(`publish`)이 같은 편집기를 열고, 현재 경로를 미리 채워 줍니다.
- 인기 코스 8개 추가(서울·부산·제주·강릉·경주·속초·여수). **장소 좌표는 대략값이라 실제 길안내 전 확인이 필요합니다.** 데이터는 glass-v3.js 의 X_PLACES / X_POSTS 에서 수정하세요.
- 경로 화면에서는 하단 탭바를 숨겨 잘림을 없애고, 헤더에 뒤로가기 버튼을 추가했습니다.
- 재적용: 기존과 같은 명령 `python apply_glass_v3.py <프로젝트 폴더>` (여러 번 실행해도 안전)
