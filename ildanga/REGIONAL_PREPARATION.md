# 지역별 후기 사전 준비

1. Ollama 켜기. 기존 연결 서버 창 닫기.
2. PREPARE_15_REVIEWS.cmd 실행, SocialCrawl 키 입력.
3. 실제 후기 검색/요약을 순차 수행. 외부 API 크레딧 사용.
4. 마지막 완료 N/15곳 확인. 실패 상세는 server/prewarm_report.json.
5. 같은 폴더의 CONNECT_REVIEWS.cmd 실행. 새 프로젝트를 Android Studio에서 실행.

준비 대상:
대전: 성심당 본점 / 한밭수목원 / 대전시립미술관
서울: 반포한강공원 / 서울숲 / 남산서울타워
부산: 해운대해수욕장 / 달맞이길 / 광안리해수욕장
제주: 함덕해수욕장 / 절물자연휴양림 / 제주돌문화공원
강릉: 경포해변 / 경포호 / 안목해변

장소명과 300m 이내 좌표가 유일하게 일치할 때만 요약. 공원/길 등 방문자 후기가 없거나 검색명이 다르면 미완료가 될 수 있습니다. 15곳의 실제 요약은 아직 실행되지 않았습니다. 검색 및 좌표는 실행 시 검증합니다.
서버의 review_cache 폴더에 원문/키 없이 검색 매칭과 생성된 요약을 7일간 재사용하도록 보관합니다. 만료된 파일은 접근 시 사용하지 않습니다. 직접 삭제하면 초기화됩니다. 제공사 저장조건에 맞춰 TTL을 조정하세요. 다른 PC로 옮길 때 해당 폴더도 함께 복사하면 준비한 요약이 유지됩니다.
준비된 장소도 연결 서버는 켜져 있어야 합니다. 새 장소에는 첫 수집 대기가 필요합니다. 요약이 없는 장소에 가짜 요약을 채우지 않습니다.
