# 일단가 v2.9

## 적용
새 폴더에 압축을 풀고 Android Studio에서 ildanga_v2_9을 열어 동기화 후 기존 PLEOS에 Run하세요. 앱을 삭제하지 마세요. 기존 카카오 서버 창이 켜져 있으면 그대로 사용합니다.

## 변경
- 방문지 사이마다 + 버튼: 앞 장소 기준 5km 검색 후 정확히 누른 위치에 삽입합니다. 끝의 +는 마지막에 추가합니다.
- 방문지 선택 시 인접 구간만 지도에 표시하고 해당 도로 경로 전체가 들어오도록 자동 확대합니다.
  - 첫 방문지: 1–2
  - 중간 3번: 2–3과 3–4
  - 마지막 방문지: 직전–마지막
- 각 구간별 도로 거리(km), 예상 주행시간(분/시간)을 지도 아래 크게 표시합니다.
- OSRM 예상 주행시간 / 교통·체류시간 미반영 표시. 실제 교통 반영 내비게이션이 아닙니다.
- 도로 조회 실패 시 해당 구간 수치 대신 실패 표시와 점선 방문 순서만 제공합니다.
- 장소 추천·이전/처음 복원·순서 편집·저장 기능 유지.

## 검증
DOM 기반 흐름 테스트 통과: 원하는 사이 위치 삽입, 첫/중간/끝 인접 구간 선택, 거리/시간 표시, 조회 실패 시 수치 미표시, 기존 추천/되돌리기/저장 회귀 테스트.
JavaScript 구문 검사 통과. 실제 Android APK 빌드 및 PLEOS 화면 렌더링은 이 환경에서 수행하지 못했습니다.
