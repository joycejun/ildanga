# 일단가 v2.11 실행

1. 기존 장소 연결 서버의 검은 창을 닫습니다. Ollama는 켜 둡니다.
2. 이 폴더를 Android Studio로 열고 Sync 후 app을 PLEOS 에뮬레이터에 실행합니다.
3. 이 폴더의 CONNECT_REVIEWS.cmd를 실행하고 SocialCrawl 키와 Kakao REST 키를 입력합니다. 입력 문자는 표시하지 않습니다.
4. 서버 창을 열어 둔 채 여행 지도에서 실제 장소를 선택합니다. 후기 요약이 자동으로 표시됩니다.

이미 설치한 qwen2.5:1.5b를 사용합니다. 재설치할 필요 없습니다.
매장 이름 및 좌표 300m 이내 또는 동일 주소가 유일하게 일치할 때만 연결합니다. 미확인 매장은 요약을 대신 만들지 않습니다.
원문/근거 펼치기/요약 시작 버튼은 표시하지 않습니다. 출처 링크는 유지합니다.
실제 받은 후기 중 최대 8개, 각 600자까지 요약합니다. 처음에는 수집 및 모델 실행 시간이 필요하며 즉시 표시를 보장하지 않습니다.
완성 결과는 앱 세션과 서버 메모리(30분)에 재사용합니다. 서버 재시작 시 서버 캐시는 사라집니다. 동일 요청은 중복 수집하지 않습니다. 오류도 재시도 폭주 방지를 위해 보관합니다. 오류 해결 후 서버와 앱을 다시 시작하세요.
장소 선택 시 외부 후기 검색/수집 API 크레딧이 자동 사용됩니다. 무료 무제한이 아닙니다. 원문 표시 여부와 무관하게 제공사 및 원출처 이용조건 확인이 필요합니다.

검증: Python 단위 테스트, 모의 API 기반 화면 동작 테스트 통과. 실제 API 키, 사용자 PC의 Ollama 성능 및 Android 빌드는 이 환경에서 검증하지 않았습니다.
